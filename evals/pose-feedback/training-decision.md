# Training decision — deferred pending evidence

No training is justified by the evidence currently available. The real manifest contains zero examples; no held-out detector or instruction accuracy has been measured, and no model has been trained or downloaded for this work.

After collecting the rights-cleared pilot, classify errors as detection, identity association, geometry, cue selection, wording or temporal stability. Correct joints with incorrect advice call for comparator/ranking/copy changes. Missing joints cannot be recovered by a landmark-only classifier. Consider an image-crop or detector alternative only after measuring that failure slice. Gesture recognition may justify a small classifier only when reliable input exists and rules underperform.

Before a training proposal, record dataset/model licenses and consent for training, a frozen connected-component split, data/model hashes, target hardware and a rules baseline. Compare candidates on identical examples; fit only training data and tune only calibration data. If test results influence changes, retire that test version and collect a new untouched final set. Public gesture classes alone do not label corrective directions.

Approve integration only with improved failing-slice accuracy without loss of correction precision, abstention quality, latency or battery acceptability. Validate the exported Core ML model on the actual phone. Desktop metrics and synthetic landmarks do not establish this gate. A trained component requires a separate approved implementation plan.
