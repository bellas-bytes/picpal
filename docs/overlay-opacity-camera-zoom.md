# Reference opacity and camera zoom controls

User request: adjustable reference-overlay opacity and zoom controls resembling the built-in iPhone Camera app. The bounded implementation uses a persistent 0–100% opacity setting (default 30%), zoom presets derived from the current supported range, pinch zoom, and fine adjustment. Selected opacity is retained through extraction/matching; zero opacity should hide image/tint while leaving controls usable.

Apple documents pinch zoom and holding the zoom control for fine adjustment in [iPhone camera basics](https://support.apple.com/guide/iphone/iph263472f78/ios). Labels must use AVFoundation's display zoom multiplier, with raw device values used for hardware commands. No additional field of view is implied by changing labels or controls.

Preserve the stable preview hierarchy across rotation and invalidate reference geometry when zoom changes. Manual zoom must not be fought by automatic zoom. Camera switching and capture must block stale gestures. Verify portrait and landscape rendered controls in addition to numeric zoom/opacity behavior.

Implementation: `ReferenceOpacityControl` persists opacity using AppStorage. The reference-orientation label shares its stack, so expanded zoom controls cannot overlap it. The ghost image no longer intercepts touches; the X remains its dismissal control, while pinch and tap-to-focus can reach the preview. Zoom starts manual, exposes supported preset positions and current magnification, and tap/hold on the current value opens fine adjustment. Pinch uses one baseline per gesture rather than multiplying repeatedly against delayed hardware feedback, and cancellation blocks a gesture from carrying across capture, camera switches or orientation changes.

Independent code review approved the implementation after correcting blocked-start pinch cancellation and expanded-control overlap. Focused validation passed 20 tests across four suites before the final regression additions.
